# 前端转 Agent 应用开发 · 学习路线与资料清单（Python 路线）

> 目标岗位：AI 应用开发工程师 / Agent 开发工程师 / LLM 应用工程师
> 时间参考：全职约 3~4 个月；在职约 6 个月。以"做出 1-2 个能演示的项目"为毕业标准，而不是"学完所有资料"。

---

## 一、总路线（5 步）

```
第1步 Python 工程化（2~3周）
   ↓
第2步 大模型 API 调用（1~2周）
   ↓
第3步 RAG 检索增强 + 向量数据库（2~3周）
   ↓
第4步 Agent 框架：LangChain / LangGraph + MCP（3~4周）
   ↓
第5步 全栈落地项目（持续 4~6 周，边学边做）
```

**建议配速**：每天 2~3 小时，前 4 步别恋战，能跑通 demo 就进下一步；第 5 步占一半时间。

---

## 二、第1步：Python 工程化（2~3周）

> 你有编程底子，这步快，重点补 Python 特有写法：异步、类封装、依赖管理、FastAPI 接口。

| 资源 | 链接 | 说明 |
|---|---|---|
| 廖雪峰 Python 教程 | https://liaoxuefeng.com/books/python/introduction/index.html | 中文免费、体系最全，零基础到进阶 |
| 菜鸟教程 Python3 | https://www.runoob.com/python3/python3-tutorial.html | 速查 + 大量实例，配合廖雪峰用 |
| W3Schools Python（英文） | https://www.w3schools.com/python/ | 英文循序渐进，可当补充 |
| FastAPI 官方中文文档 | https://fastapi.tiangolo.com/zh/ | Agent 后端接口必用框架 |

**第1步验收**：能用 FastAPI 写一个带 GET/POST 接口的小服务，跑通本地。

## 三、第2步：大模型 API（1~2周）

> 重点是：流式输出、Function Calling（工具调用）、多轮对话、上下文管理。国内模型 API 都是 OpenAI 兼容格式，学一家会全家。

| 资源 | 链接 | 说明 |
|---|---|---|

| DeepSeek 首次调用 API | https://api-docs.deepseek.com/zh-cn/index.html | 从注册、拿 key 到第一个调用 |
| 豆包大模型（火山引擎） | https://www.volcengine.com/docs/82379/1099349 | 字节系模型，国内最主流的落地选择之一 |
| OpenAI API 参考（英文） | https://developers.openai.com/api/reference/overview | 理解标准接口/参数语义 |
| 各家官方文档合集 | https://github.com/hkai-ai/LLM_OFFICIAL_DOCUMENTATION | OpenAI/Gemini/DeepSeek/Kimi 文档导航 |

**第2步验收**：用 Python 调通 DeepSeek（或豆包），实现：普通对话 + 流式输出 + Function Calling（让模型调用你写的一个自定义工具函数）。

## 四、第3步：RAG + 向量数据库（2~3周）

> RAG 是 Agent 岗面试必考、企业落地最频繁的需求，一定要亲手搭一遍全链路：解析 → 分块 → Embedding → 向量库 → 检索 → 重排 → 生成。

| 资源 | 链接 | 说明 |
|---|---|---|
| RAG 原理深度解析 | https://juejin.cn/post/7649206162342821938 | 从语义检索讲到防幻觉，含 Chroma 代码 |
| 向量数据库选型指南 | https://juejin.cn/post/7626240732471558179 | Chroma vs Milvus vs Pinecone 怎么选 |
| Milvus 新手训练营 | https://milvus.org.cn/bootcamp | 官方中文训练营，含 RAG/多模态案例 |

**建议组合**：开发调试用 **Chroma**（轻量本地），了解 **Milvus**（生产级）；先跑通一个"上传 PDF → 问答"的 demo。

**第3步验收**：做一个"企业知识库问答"：喂 3~5 份文档，能基于文档内容回答且标注来源。

## 六、第5步：全栈落地项目（4~6周，最重要）

> 一定要做"带前端界面"的 Agent —— 这是你作为前端工程师和普通转行者拉开差距的杀手锏。

**推荐项目（选 1~2 个做透）：**

1. **企业知识库 Agent**（最稳）：前端聊天界面 + 后端 RAG 问答，支持文档上传、流式回复、来源标注。
2. **带工作流的业务 Agent**：前端可视化编排 + 后端 LangGraph 工作流（如"自动生成周报并发送"）。
3. **个人研究助手**：输入主题 → 联网搜索 → 整理文献 → 生成综述报告。

## 七、避坑提醒（别踩）

1. **别只学框架不写代码**：框架更新快（LangChain 一年换好几次 API），重要的是理解"检索、工具调用、状态管理"这些底层逻辑，别死记 API。
2. **别被"月薪 25K 起"的培训话术忽悠**：初级岗真实区间 8~15K/月，薪资是拿项目换的，不是上课换的。
3. **项目 > 证书**：面试官要的是"能从头到尾讲清楚的项目"，GitHub 上 1 个完成度高的项目 > 10 张认证。
4. **前端别丢**：你的 Agent 项目一定带前端界面，这是你和 90% 纯后端转行者差异化的地方。
